# 표지 이미지

자료 표지를 여기 넣습니다. 시트 `coverImage` 열에는 **파일 이름만** 적습니다.

```
public/covers/sen-250107-h1g.jpg   ←  파일
시트 coverImage 열:  sen-250107-h1g.jpg
```

- 파일 이름은 자료 `id`와 같게 두면 나중에 찾기 쉽습니다.
- 가로 **600px** 정도면 충분합니다. 그보다 크면 첫 화면이 무거워집니다.
- `.jpg` `.png` `.webp` `.avif` 만 받습니다.
- 외부 주소(`https://...`)는 쓸 수 없습니다. 남의 서버 이미지를 끌어다 쓰면
  그쪽이 파일을 옮기는 순간 깨지고, 트래픽도 그쪽에 떠넘기게 됩니다.
- 비워 두면 기관 색으로 만든 카드가 대신 나옵니다. 빈칸이어도 화면은 멀쩡합니다.

## 넣기 전에 확인할 것

원문 페이지에 **무단 전재·복제 금지**나 "수업 목적으로만 사용" 같은 안내가 있으면
표지를 그대로 올리기 전에 발행 부서에 물어보세요. 판단이 서지 않으면 비워 두면 됩니다.
