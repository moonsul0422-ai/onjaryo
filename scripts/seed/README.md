# 시드 데이터 (개발용)

이 폴더의 CSV는 **개발·빌드 검증용 예시 데이터**다. 실제 아카이브에 실릴
검증된 목록이 아니다.

- `SHEET_ID` 환경변수가 없거나 시트를 읽지 못하면 `scripts/fetch-sheet.mjs`가
  이 파일들로 대신 빌드한다. 빌드가 시트 상태에 인질로 잡히지 않게 하기 위함이다.
- 이때 `src/data/meta.json`의 `source`가 `seed` 또는 `seed-fallback`이 되고,
  사이트 하단에 "예시 데이터" 표시가 붙는다.
- `sourceUrl`은 각 기관의 실제 대표 사이트를 가리킨다. 개별 문서의 깊은 링크는
  임의로 지어내지 않았다.
- 마지막 세 행은 일부러 흠이 있는 행이다(요약 없음 / 영역 없음 / 비공개).
  sync 경고와 제외 동작을 확인하는 용도이므로 지우지 말 것.

실제 운영에서는 `SHEET_ID`를 설정해 구글 시트를 원천으로 쓴다. 시트 열 이름은
`scripts/fetch-sheet.mjs`의 `FIELD_ALIASES` / `ORG_ALIASES`가 받아 준다
(영문 키와 한글 열 이름 모두 인식).
